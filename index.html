01 / DISCLOSURE

Keep the next step clear.

What can I do without a mouse?

Use Tab to reach a control, Enter or Space to activate it, and arrow keys to change a radio selection. Native details elements expose their state to assistive technology.

Is any data stored?

No application storage exists in this static lab. Controls reset on a fresh page load; the browser may restore form state through its own navigation behavior.

05 / 06 — REVIEW IN CONTEXT

A repeatable review.

Keyboard pass

  1. Reload and press Tab. The skip link should appear.
  2. Follow each visible focus ring.
  3. Open a disclosure and change a radio with arrow keys.
  4. Submit the empty form and check the required-field response.

Screen-reader pass

  1. Navigate landmarks and heading levels.
  2. Check field names, help text and required state.
  3. Confirm disclosure and checkbox state announcements.
  4. Compare reading order with the visible layout.

Screen-reader behavior needs manual verification on your intended platform.

Layout pass

Resize to a narrow phone, zoom text, switch color theme and enable reduced motion. Automated browser checks and screenshots live in the repository's test workflow.
